# Collection Preview

Before you save a new or edited collection you can preview what it will look like in Plex. The preview allows you to see which items are in the source list and which items exist in your library, with the option to download individual missing items.

## Opening the Preview

1. Edit or create a collection.
2. Fill out the required fields
3. Click **Preview Collection** in the bottom-right of the form.

## What You’ll See

- **Source items** – the titles that match your collection settings, shown with posters and basic info.
- **Availability** – borange border indicates whether each item already exists in your Plex libraries.
- **Library tabs** – when you target multiple libraries the preview lets you switch between them to see how each library will appear.
- **Manual downloads** – trigger a download or Overseerr request for a specific title straight from the preview while you review it.
