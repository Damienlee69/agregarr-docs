# Create Placeholders for Missing Items

When **Create Placeholders for Missing Items** is selected, Agregarr will create placeholders in Plex with a trailer downloaded from YouTube. This allows you to get the full benefits of lists without having to use terabytes of storage. Used in conjunction with the Overlays feature, overlays can be added to these placeholders indicating that it is a placeholder and needs to be requested.

## How to use

- Select the **Create Placeholders for Missing Items** checkbox in the collection creation form
- Select parameters for future and recently released content
- Ensure you have correctly mounted your media folders and that they have been setup in Agregarr under **Settings -> Downloads**
- Enable the default Overlays for missing items in **Posters -> Poster Overlays**
