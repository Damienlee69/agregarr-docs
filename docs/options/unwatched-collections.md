# Unwatched Collections

The **Unwatched Only** toggle creates a paired smart collection that shows each Plex user only the titles they have not watched yet.

## What Happens When Enabled

- Agregarr keeps the original collection hidden in the background and creates a smart collection that is based off that original collection and has the unwatched filter applied.
- Each user sees only their own unwatched items (this is a Plex Smart Collections feature)
- The smart collection inherits posters, visibility, and scheduling from the primary collection.

## Sorting Options

- Choose from Plex’s smart collection sort list to define how the unwatched results should be ordered.
- Release-date (newest first) is the default because it highlights the latest additions while the base collection retains source ordering.
- Plex cannot preserve the original list order for smart collections, so pick a sort mode that aligns with the list.
