# Selecting Libraries

- Library labels are pulled directly from Plex, so renaming a library in Plex updates the choices shown here.

## Media-Type Detection & Messages

- Custom lists sources trigger a quick analysis to determine whether the list contains movies, TV, or both; you can still create collections for non-matching libraries, but a warning will be shown.

## Multi-Library Considerations

- Selecting both movie and TV libraries unlocks separate template fields, letting you tailor names per media type.
- Poster uploads are organised per library, so picking multiple libraries enables the per-library poster actions.
