# Random Home Order

This toggle shuffles the collection’s position among other collections with this option enabled whenever Agregarr runs the main collections sync or the randomise order sync (both set in **Settings -> Jobs**)

## What It Does

- Applies only to the Plex home and recommended views; the collection’s position inside the library view stays unchanged.
- Can be used with pre-existing collections and default hubs
