# Config Options

1. **Choose a source** – select the parent source you want to use. Ensure your API keys are set if required.
2. **Pick a sub-type** – select the specific list you want to use, inlcuding custom lists
3. **Select target libraries** – select one or many libraries, individual collections will be created for each

- [Library Selection](./library-selection) – choose which Plex libraries receive the collection.
- [Titles & Templates](./titles) – control how Agregarr names the collection per library.
- [Source Specific Options](./source-specific-options) – settings that depend on the chosen provider or tag type.
- [Visibility](./visibility) – decide where Plex surfaces the collection and how inactive periods behave.
- [Max Items](./max-items) – cap how many items Plex keeps in the collection.
- [Unwatched Collections](./unwatched-collections) – create smart, per-user unwatched views.
- [Posters](./posters) – auto-generate artwork or upload custom posters per library.
- [Time Restrictions](./time-restrictions) – schedule when a collection is considered active.
- [Custom Sync Timing](./custom-sync-timing) – override the default sync cadence or supply a cron expression.
- [Missing Items & Auto Requests](./missing-items) – optionally download or request items that are missing from Plex.
- [Random Home Order](./random-home-order) – shuffle the collection’s position on the Plex home screen.

## Preview Before Saving

When all mandatory fields are satisfied the **Preview Collection** button activates. Use it to view matching items in Plex and add missing items individually.
