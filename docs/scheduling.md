# Time Restrictions & Scheduling

Schedule when collections are visible using time-based restrictions.

## Date Ranges

Show collections during specific calendar periods.

**Examples**:
- Halloween: October 1 - October 31
- Most Popular This Year: December 1 - January 1
- Summer: June 1 - August 31

Enter in the format DD-MM

## Day of Week

Show collections only on certain days.

**Examples**:
- Weekend Movies: Saturday + Sunday
- Thriller Thursday: Thursday only

## Combining Restrictions

Mix restriction types for sophisticated scheduling.

**Example - Halloween Horror Marathon**:
- Dates: October 1-31
- Days: Friday, Saturday, Sunday

Result: Horror only on October weekends

## Inactive Behavior

When restrictions make collection inactive:

**Remove from Plex**: Deletes collection entirely

**Visibilty options**: Keep the collection in Plex when inactive, but change the visibility settings

## Rotation Examples

**Daily rotation** - different genre each day:
- Monday: Action
- Tuesday: Thriller
- Wednesday: Western
- etc.

**Monthly rotation** - different theme each month:
- January: Awards nominees
- February: Romance
- March: International
- etc.
