# Radarr & Sonarr

Use this mode when you want missing items added directly to Radarr or Sonarr.

## Setup

1. Open **Settings → Downloads**.
2. Click **Add Radarr** or **Add Sonarr**.
3. Enter:
   - Set Default (one required)
   - Server name
   - Hostname or IP (for example `192.168.0.236`).
   - Port (`7878`)
   - API key (from Radarr/Sonarr → Settings → General).
4. Click **Test**. If it succeeds, pick the quality profile and root folder you want as defaults.
5. Optional: set tags you always want applied or enable automatic tag creation by source.
6. Click **Save**.

Repeat for extra servers if needed.
