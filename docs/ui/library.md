# Library View

Library controls what users see when they open a Plex library tab. Drag and drop to reorder promoted collections.

## Sections

- **Promoted** – Items you pin to the top of the library. Promoted using !!!!! as the sort title. Drag to reorder or demote them back to A–Z.
- **A–Z** – Everything else, listed alphabetically. This includes pre-existing collections that might have existing sort title set, which won't be altered by Agregarr unless promoted.

## Notes

- Every Agregarr collection always appears somewhere in the library tab, even if Home and Recommended are disabled.
- Apply time restrictions with the "Remove from Plex when inactive" option when you want a collection to disappear completely outside certain dates.
