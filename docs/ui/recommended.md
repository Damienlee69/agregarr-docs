# Recommended View

Recommended controls Plex’s “Recommended” tab for each library.

## Tasks

- Pick a library from the tabs and drag items to set the order for that library.

## Notes

- Collections only appear here when the Recommended toggle is enabled in the collection form.
- Ordering here does not affect Library. Because Home and Recommended share ordering in Plex, if an item is visible in both Home and Recommended, it's order must be controlled on the Home screen (which will then be reflected in the Recommended screen)
- Plex Pass is required for Plex to use your Recommended ordering.
