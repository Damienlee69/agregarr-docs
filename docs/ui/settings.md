## Tabs

- **General** – App title, base URL, CSRF protection, locale, proxy, regenerate API key.
- **Plex** – Connect to Plex
- **Sources** – Enter API keys/server details for sources
- **Downloads** – Add Radarr/Sonarr/Overseerr servers, set source identification.
- **Logs** – Review Agregarr logs
- **Jobs** – Run jobs manually, change Collections Sync and Randomise order schedule
- **About** – Check version and update information.
