# Home View

Home controls the collections that appear on Plex home screens.

## Tasks

- Drag items to set the order for regular users and the server owner.

## Notes

- Only collections marked for Home visibility show up here.
- Ordering changes here do not affect the Library tabs, but does affect the Recommended ordering.
- Plex Pass is required for Plex to promote collections to the home screen.
