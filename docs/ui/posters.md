# Posters Workspace

Use Posters to create templates and manage saved artwork. Templates can be selected per-collection in the relevant config

## Tabs

- **Templates** – Create, duplicate, or import template ZIP files.
- **Saved Posters** – View rendered or uploaded posters.

## Elements

**Background** - You can either use a single background colour/s for this template, or set it to use source colours, which will change the colour/s depending on which source the template is being used for. Source colours can be adjusted individually. Gradient options are available.
**Add Custom Text** - Adds a custom text element with resizing, font, and colour options
**Add Collection Title** - Adds a placeholder that will be dynamically filled with the collection title. The box can be resized to define the limits of how much space the dynamic text can take up. Adjusting the max lines slider will allow the text to be resized to fit longer titles.
**Add Image** - Add a raster image (png, jpg)
**Add Source Logo** - Adds a placeholder that will be dynamically filled with the sources logo 
**Add Custom SVG Icon** - Add a custom SVG icon
**Add Grid** - Adds a resizeable content grid, which will be filled with the posters from the top X items from the final collection
