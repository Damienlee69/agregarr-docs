# Navigating the UI

The sidebar shows every page. Use this list as a quick reference.

- **Home** – Arrange the collections that appear on Plex home screens. [Home guide](./home)
- **Recommended** – Recommended tab for each library (shared ordering with Home). [Recommended guide](./recommended)
- **Library** – Arrange the collections that appear inside each Plex library (independent ordering). [Library guide](./library)
- **All Collections** – View and edit every collection, hub, and pre-existing list. [All Collections guide](./all-collections)
- **Posters** – Create templates and manage saved posters. [Posters guide](./posters)
- **Dashboard** – Check most viewed collections, and missing items (work in progress). [Dashboard guide](./dashboard)
- **Settings** – Configure plex server, sources, downloads, jobs, logs, and about info. [Settings guide](./settings)
