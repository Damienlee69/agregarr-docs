# Network Originals

Network Originals uses Kometas MDBList to get originals from major streaming services.
## Prerequisites

- An MDBList API key configured under **Settings → Sources → MDBList**. The originals endpoint reuses the same credentials as standard MDBList lists.

## Sub-types

Choose one of the supported platforms:

- Netflix Originals
- Amazon Originals
- Disney+ Originals
- HBO Max Originals
- Paramount+ Originals
- Hulu Originals
- Peacock Originals
- Apple TV+ Originals
- Discovery+ Originals
