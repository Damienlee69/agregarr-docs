# Network Top 10

The Network Top 10 source pulls daily streaming charts via FlixPatrol. It is a quick way to show what is popular on major platforms in your region without any API keys.

## Configuration Steps

1. Select **Network Top 10** from the Collection Type list.
2. Pick a **Country/Region**. The dropdown is populated dynamically
   - `Global` mirrors worldwide charts curated by FlixPatrol and is usually the best choice for mixed libraries.
   - Country-specific feeds are helpful when you have local only platforms, but some regions merge movies and TV into a single top 10 chart so you will have limited items in the final collection.
3. Choose a streaming **Platform** for the selected country.
4. Configure titles, max items, posters, and any other options as usual.
