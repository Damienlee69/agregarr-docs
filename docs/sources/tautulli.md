# Tautulli Statistics

Tautulli-based collections surface what your Plex users actually watch.

## Prerequisites

Setup Tautulli in **Settings → Sources → Tautulli** in Agregarr.

## Sub-types

| Option | Description | Additional inputs |
| --- | --- | --- |
| Most Popular (Play Count) | Orders items by number of plays | Requires **Number of Days** and **Minimum Play Count**. |
| Most Popular (Watch Duration) | Orders by total time watched | Same inputs as above. |

### Number of Days

Defines the look-back window for Tautulli stats (1–365 days).

### Minimum Play Count

Filters out titles with very little activity. Set to `1` to include everything, or raise it to show more popular content.
