# MyAnimeList

Agregarr integrates via API, which requires a Client ID.

## Prerequisites

1. Visit [myanimelist.net/apiconfig](https://myanimelist.net/apiconfig) and create an application.
2. Set:
   - **Application Type**: Web
   - **Redirect URL**: `http://localhost/`
   - **Homepage URL**: `https://github.com/agregarr/agregarr`
   - **Usage**: Hobbyist / Non-commercial
3. Copy the **Client ID**.
4. In Agregarr open **Settings → Sources → MyAnimeList**, paste the Client ID, test, and save.

## Sub-types

| Option | Description |
| --- | --- |
| Top Anime Series | Highest-rated anime overall |
| Top Airing Anime | Rankings for currently airing series |
| Top Anime TV Series | TV-only chart |
| Top Anime Movies | Movie-only chart |
| Top OVA Series | Original video animation chart |
| Top Anime Specials | Specials and one-off episodes |
| Most Popular Anime | Ordered by member count |
| Most Favorited Anime | Ordered by user favourites |
