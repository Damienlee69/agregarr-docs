# Radarr & Sonarr Tags

Tag-based collections mirror the tags you already manage inside Radarr or Sonarr.

## Prerequisites

1. Configure your Radarr and/or Sonarr servers under **Settings → Downloads** in Agregarr. 
2. Create tags within Radarr/Sonarr for the titles you want to use.

## Creating a Collection

1. Choose the **Radarr Tag** or **Sonarr Tag** collection type.
2. Pick the Radarr or Sonarr instance from the dropdown. Agregarr lists every configured server.
3. Select the tag you want to use. The tag list populates only after the instance is chosen to avoid mismatches.
4. Complete the rest of the form (templates, posters, max items, scheduling, etc.).

## Behaviour

- Radarr Tag collections only target movie libraries; Sonarr Tag collections only target TV libraries. The library picker warns you if you attempt to mix media types.
